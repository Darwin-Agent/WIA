Core Building Blocks

从世界理解到世界行动

WIA 不是被动模拟器，而是把环境预测能力延伸到智能体策略优化的完整体系。

▣

WIA-Corpus

覆盖 CPT、SFT、RL 的全生命周期训练语料，把异构数字交互统一成 action–observation 轨迹。

◫

WIA-Bench

首个成对 ID / OOD 世界模型评测集，1.8k 域内与 1.7k 域外样本，横跨七大数字环境。

◎

WIA-WM

4B / 9B / 27B / 35B-A3B / 122B-A10B 基础世界模型，系统化建模状态转移，并支持模拟 SFT、模拟 RL 与推理前瞻。

⌁

WIA-WAM

通过 Dual-Perspective Inversion 与 CSPO 耦合预测和执行，让策略隐式内化环境动力学。

↗

跨域泛化

Android、MCP、OS、Search、SWE、Terminal、Web 七域统一建模，知识不再被单一界面割裂。
